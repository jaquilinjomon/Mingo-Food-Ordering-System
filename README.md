# Mingo-Food-Ordering-System

A desktop-based Food Ordering System developed in Java using Swing for the graphical user interface and MongoDB for data storage. The application allows users to select food items, place orders, calculate the total bill, and store order details in a database. It also demonstrates multithreading and exception handling concepts in Java.

## Features

- Java Swing-based graphical user interface
- Food menu selection and order placement
- Automatic bill calculation
- MongoDB database integration
- Order history management
- Multithreaded order processing
- Custom exception handling for invalid orders
- User-friendly error pop-up messages

## Technologies Used

- Java
- Java Swing
- MongoDB
- MongoDB Java Driver
- Multithreading
- Exception Handling
